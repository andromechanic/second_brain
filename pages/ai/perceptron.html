The Perceptron

The foundational model introducing learnable weights, continuous inputs, and linear decision boundaries.

ai neural-networks perceptron linear-separability foundations
1. What Changed from McCulloch–Pitts to the Perceptron?

Invented by Frank Rosenblatt (1958), the Perceptron marks the transition from hand-crafted logical switches to genuine Machine Learning. While the M-P neuron used fixed binary inputs and pre-set connections, the Perceptron introduces numerical inputs, synaptic weights, and an algorithm to learn those weights from data.

2. Why Numerical Weights?

In biological and artificial systems, different inputs carry unequal importance. Synaptic weights (wi) quantify influence:

Weighted Sum: ∑ wi xi = w₁x₁ + w₂x₂ + ... + wnxn
Real-Life Analogy (Scholarship Score):
Score = 0.7(Marks) + 0.2(Attendance) + 0.1(Sports)
The coefficients 0.7, 0.2, and 0.1 are weights determining the relative priority of each feature.

3. Thresholding & The Bias Trick (x₀ = 1, w₀ = -θ)

The standard perceptron fires if the weighted sum meets or exceeds threshold θ:

y = 1   if   ∑i=1n wi xi ≥ θ  |  y = 0   if   ∑i=1n wi xi < θ

Rearranging by subtracting θ from both sides gives:

∑i=1n wi xi − θ ≥ 0
The Notation Trick (Absorbing the Threshold):
We define a dummy bias input x₀ = 1 and a bias weight w₀ = −θ.
Then w₀ x₀ = (-θ)(1) = -θ, allowing us to absorb the threshold directly into the summation:
∑i=1n wixi − θ  ⟶  ∑i=0n wixi

In modern machine learning notation, this is commonly written with bias b:

z = ∑ wi xi + b  ⟶  y = step(z)

4. Linear Separability & The XOR Limitation

What functions can a single perceptron compute? Only linearly separable functions.

The decision boundary between class 1 and class 0 is defined where:

w₁x₁ + w₂x₂ + b = 0  (A straight line in 2D / hyperplane in nD)
The Famous Limitation: XOR Cannot be Solved by a Single Perceptron:
While AND, OR, and NOT are linearly separable (a single straight line can partition output 1 from 0), the XOR truth table places points diagonally. No single straight line can separate them. This historical insight (Minsky & Papert, 1969) motivated the later evolution toward multi-layer neural networks.

5. McCulloch–Pitts vs. Perceptron

Feature McCulloch–Pitts (1943) Perceptron (1958)
Inputs Binary only {0, 1} Continuous numerical values ℝ
Synaptic Weights None (fixed +1 or veto) Arbitrary numerical weights (wi)
Learning Ability ❌ Hand-designed ✅ Learned via Perceptron Learning Rule
Threshold Fixed integer θ Absorbed into bias weight (w₀ = −θ)
Decision Boundary Discrete logic constraints Linear hyperplane (∑ wixi + b = 0)
Can Solve XOR? ❌ No (single unit) ❌ No (requires multi-layer)

6. Perceptron Learning Algorithm & Python Simulation

Weights are adjusted iteratively when predictions mismatch ground truth:

Weight Update Rule: winew = wiold + η(y − ŷ)xi

where η is the learning rate, y is ground truth, and ŷ is the prediction.

def perceptron(x1, x2, w1, w2, b):
    """Simple 2-input perceptron with step activation."""
    z = w1 * x1 + w2 * x2 + b
    return 1 if z >= 0 else 0

# Linearly separable AND gate configuration
w1, w2, b = 1, 1, -2

print("AND(0, 0) ->", perceptron(0, 0, w1, w2, b))  # 0
print("AND(0, 1) ->", perceptron(0, 1, w1, w2, b))  # 0
print("AND(1, 0) ->", perceptron(1, 0, w1, w2, b))  # 0
print("AND(1, 1) ->", perceptron(1, 1, w1, w2, b))  # 1
