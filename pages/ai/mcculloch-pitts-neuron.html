McCulloch–Pitts (M-P) Neuron

The earliest mathematical model of an artificial neuron (1943).

1. What is a McCulloch–Pitts Unit?

Proposed by Warren McCulloch and Walter Pitts in 1943, the M-P neuron is one of the foundational mathematical abstractions of biological neurons. It behaves as a binary threshold decision unit:

Inputs → Neuron → Output

The output is strictly binary:

y ∈ {0, 1}
  • 0: Neuron does not fire (inactive)
  • 1: Neuron fires (active)

2. Basic Structure & The Threshold (θ)

A typical M-P neuron receives multiple binary inputs xi ∈ {0, 1}:

x₁ ───────►
           \
x₂ ────────►  ● ─────► y
           /   Neuron
x₃ ───────►

The symbol θ (theta) is the threshold: the minimum quantity of excitation needed for the neuron to fire.

Threshold Example (θ = 2):
Suppose inputs are: x₁ = 1, x₂ = 1, x₃ = 0
Total excitation = 1 + 1 + 0 = 2.
Since 2 ≥ θ (2 ≥ 2), the neuron fires: y = 1.

If inputs were x₁ = 1, x₂ = 0, x₃ = 0 → sum is 1 < 2 → y = 0.

3. Excitatory vs. Inhibitory Inputs

Connections in an M-P unit fall into two distinct functional types:

  • Excitatory input (→): Encourages firing. When active (xi = 1), it contributes +1 toward reaching threshold θ.
  • Inhibitory input (—○): Exerts absolute veto power. Prevents firing completely.
Rule 1 — Absolute Inhibitory Priority (Veto Rule):
If ANY inhibitory input is 1, the output is immediately y = 0, regardless of how large the excitatory sum is. No further calculation is needed.
Rule 2 — Excitatory Threshold Check:
If (and only if) all inhibitory inputs are 0, evaluate:
∑ xexcitatory ≥ θ &implies; y = 1  |  otherwise y = 0

Decision Flowchart

        Any inhibitory input = 1?
                 │
          YES ───┴───► y = 0  (Veto triggered!)
                 │
                NO
                 ↓
    Sum of excitatory inputs ≥ θ ?
                 │
          YES ───┴───► y = 1  (Neuron fires)
                 │
                NO
                 ↓
                y = 0  (Sub-threshold)

4. Implementing Logic Gates with M-P Neurons

A. AND Gate (y = x₁ ∧ x₂)

Neuron fires only when both inputs are 1. Both inputs are excitatory; set threshold θ = 2 (for n inputs, θ = n).

x₁ x₂ Sum (x₁ + x₂) Sum ≥ 2? AND Output (y)
000No0
011No0
101No0
112Yes1

B. OR Gate (y = x₁ ∨ x₂)

Neuron fires if at least one input is 1. Both inputs are excitatory; set threshold θ = 1.

x₁ x₂ Sum (x₁ + x₂) Sum ≥ 1? OR Output (y)
000No0
011Yes1
101Yes1
112Yes1

C. NOT Gate (y = ¬x)

Input x is connected as an inhibitory input (x —○ •) with threshold θ = 1 (no excitatory inputs needed).

x (Inhibitory) Inhibition Active? NOT Output (y)
0No → Uninhibited, fires1
1Yes → Veto triggered0

D. NOR Gate (y = ¬(x₁ ∨ x₂))

Neuron outputs 1 only when both inputs are 0. Connect both inputs as inhibitory inputs.

x₁ (Inhibitory) x₂ (Inhibitory) Any Inhibition Active? NOR Output (y)
00None → fires1
01Yes (x₂) → veto0
10Yes (x₁) → veto0
11Yes (both) → veto0

5. Logic Function Reference

Logic Function Input Types Threshold (θ)
AND (n inputs)All excitatoryθ = n
OR (n inputs)All excitatoryθ = 1
NOT (1 input)Single inhibitory inputθ = 1 (or 0 excitatory)

Core Principle: Always inspect inhibitory inputs first. If even one inhibitory input is active (1), output is instantly y = 0.

6. Significance in AI & Comparison to Modern Neurons

The M-P neuron established the computational lineage of Artificial Intelligence:

M-P Neuron (1943) → Perceptron (1958) → Multilayer Perceptrons → Deep Learning
Property McCulloch–Pitts (M-P) Unit Modern Artificial Neuron
Input Values Binary only: {0, 1} Continuous real numbers: ℝ
Synaptic Connections Fixed weights (+1 or −∞) Learnable continuous weights (wi)
Threshold / Bias Manually predetermined θ Learned bias parameter (b)
Output Binary discrete: {0, 1} Continuous/probabilistic (ReLU, Sigmoid, Softmax)
Learning Mechanism None (hand-designed) Gradient Descent & Backpropagation

7. Python Simulation

A reference Python implementation demonstrating inhibitory veto and threshold checking:

def mp_neuron(excitatory_inputs, inhibitory_inputs, threshold):
    """
    Simulate a McCulloch-Pitts neuron.
    
    Rule 1: Absolute inhibition priority (veto).
    Rule 2: Excitatory sum >= threshold.
    """
    # Rule 1: Check inhibitory veto
    if 1 in inhibitory_inputs:
        return 0
    
    # Rule 2: Evaluate excitatory sum against threshold
    return 1 if sum(excitatory_inputs) >= threshold else 0

# Test Gates
print("AND(1, 1):", mp_neuron([1, 1], [], 2))       # 1
print("AND(1, 0):", mp_neuron([1, 0], [], 2))       # 0
print("OR(1, 0): ", mp_neuron([1, 0], [], 1))       # 1
print("NOT(0):   ", mp_neuron([], [0], 1))          # 1
print("NOT(1):   ", mp_neuron([], [1], 1))          # 0
print("NOR(0, 0):", mp_neuron([], [0, 0], 1))       # 1
print("NOR(0, 1):", mp_neuron([], [0, 1], 1))       # 0
